รองรับ AI Workflow อะไรบ้าง? URL เดียวด้านล่างนี้เชื่อมต่อพร้อมกันได้ทุก AI Agent เพื่อสั่งอัปโหลดภาพ/วิดีโอ/เสียงจาก URL, สั่ง Generate วิดีโอ, เช็กคิวงานแบบ Real-time, ดึงลิงก์ดาวน์โหลดไฟล์ .mp4, และยกเลิกงานอัตโนมัติ

  1. Claude Code (CLI): claude mcp add --transport http tony URL
  2. OpenAI Codex (CLI): codex mcp add tony --url URL
  3. Cursor / Antigravity / Windsurf: เพิ่ม MCP Server ประเภท streamable-http หรือ http แล้ววาง URL ด้านบน
  4. Claude Desktop / Claude.ai: Settings → Connectors → Add custom connector → วาง Public HTTPS URL
  5. ตัวอย่างคำสั่งในแชท: “เช็กสถานะ Tony ดูรูปที่อัปไว้ แล้วสร้างคลิป 9:16 ยาว 8 วินาที พอเสร็จแล้วส่งลิงก์ดาวน์โหลดมาให้หน่อย”
